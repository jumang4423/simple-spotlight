# Simple Spotlight

![Simple Spotlight](ss.png)

Tiny macOS launcher, calculator, and `yt-dlp` helper.

- Launch apps from `/Applications` and `~/Applications`
- Calculate expressions
- Download YouTube URLs as MP3 to `~/Downloads`
- Learns app ranking from what you actually open

```sh
scripts/build_app.sh release
open "build/Simple Spotlight.app"
```

Press `Option + Space`.
